# List all valid shapeclasses

List all valid shapeclasses

## Usage

``` r
list_all_shapeclasses()
```

## Value

vector of valid shapeclasses

## Examples

``` r
list_all_shapeclasses()
#>  [1] "D2"                       "D3"                      
#>  [3] "D3_hom"                   "D4"                      
#>  [5] "D4_hom"                   "D5"                      
#>  [7] "D5_hom"                   "D6"                      
#>  [9] "D6_hom"                   "D7"                      
#> [11] "D7_hom"                   "D8"                      
#> [13] "D8_hom"                   "Edge-capped tetrahedron" 
#> [15] "Face-capped tetrahedron"  "Face-capped cube"        
#> [17] "Edge-capped cube"         "Edge-capped octahedron"  
#> [19] "Edge-capped icosahedron"  "Face-capped icosahedron" 
#> [21] "Edge-capped dodecahedron"
```
